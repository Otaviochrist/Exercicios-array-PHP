# Exercícios de PHP — arrays

Pratique arrays associativos, numéricos e aninhados. Cada arquivo tem dados de exemplo, enunciado em comentário e `TODO`. **Não há gabarito nestes arquivos.**

## Como rodar

No terminal, na pasta deste projeto:

```bash
php exercicios-php/01-aquecimento.php
```

Troque o número do arquivo conforme for avançando.

## Ordem sugerida

| # | Arquivo | O que treina |
|---|---------|----------------|
| 1 | `01-aquecimento.php` | Cópia do array vs original; `sort()` vs `min()` |
| 2 | `02-varios-produtos.php` | Vários produtos; menor preço de cada um |
| 3 | `03-comparar.php` | Menor preço global e média mais alta |
| 4 | `04-filtrar.php` | `array_filter` |
| 5 | `05-transformar.php` | `array_map` |
| 6 | `06-agrupar.php` | Agrupar por chave (categoria) |
| 7 | `07-ordenar.php` | `usort` |
| 8 | `08-carrinho.php` | Estrutura aninhada: subtotal, total, item mais caro |

Funções úteis para consultar na documentação do PHP: `min`, `max`, `array_sum`, `count`, `array_filter`, `array_map`, `array_reduce`, `array_column`, `usort`.

Se travar, peça uma dica (não a resposta completa).
