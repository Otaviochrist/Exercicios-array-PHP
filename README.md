## 🇧🇷 Português

### Sobre o projeto

Série de exercícios práticos em PHP para treinar arrays associativos, numéricos e aninhados.

Cada arquivo em `exercicios-php/` traz dados de exemplo, enunciado em comentário e `TODO`. Não há gabarito nestes arquivos — o objetivo é resolver sozinho, consultando a documentação quando precisar.

### Como usar

1. Abra o terminal na pasta do projeto
2. Execute o exercício desejado, começando pelo primeiro:

```bash
php exercicios-php/01-aquecimento.php
```

3. Avance na ordem sugerida, trocando o número do arquivo

### Ordem sugerida

| # | Arquivo | O que treina |
|---|---------|----------------|
| 1 | `01-aquecimento.php` | Cópia do array vs original; `sort()` vs `min()` |
| 2 | `02-varios-produtos.php` | Vários produtos; menor preço de cada um |
| 3 | `03-comparar.php` | Menor preço global e média mais alta |
| 4 | `04-filtrar.php` | `array_filter` |
| 5 | `05-transformar.php` | `array_map` |
| 6 | `06-agrupar.php` | Agrupar por chave (categoria) |
| 7 | `07-ordenar.php` | `usort` |
| 8 | `08-carrinho.php` | Estrutura aninhada: subtotal, total, item mais caro |

### O que aprendi desenvolvendo este projeto

- Arrays associativos, numéricos e aninhados em PHP
- Funções de array: `min`, `max`, `array_sum`, `count`, `array_column`
- `array_filter`, `array_map` e `array_reduce`
- Ordenação com `sort` e `usort`
- Percorrer estruturas aninhadas (produto → preços, carrinho → itens)

### Tecnologias

- PHP
- Git

## 🇺🇸 English

### About the project

A set of PHP exercises to practice associative, numeric, and nested arrays.

Each file in `exercicios-php/` includes sample data, a comment with the prompt, and `TODO`s. There is no answer key in these files — the goal is to solve them yourself and look up the docs when you get stuck.

### How to use

1. Open a terminal in the project folder
2. Run the exercise you want, starting with the first one:

```bash
php exercicios-php/01-aquecimento.php
```

3. Follow the suggested order, changing the file number as you go

### Suggested order

| # | File | What it trains |
|---|---------|----------------|
| 1 | `01-aquecimento.php` | Copying an array vs the original; `sort()` vs `min()` |
| 2 | `02-varios-produtos.php` | Several products; lowest price of each |
| 3 | `03-comparar.php` | Global lowest price and highest average |
| 4 | `04-filtrar.php` | `array_filter` |
| 5 | `05-transformar.php` | `array_map` |
| 6 | `06-agrupar.php` | Group by key (category) |
| 7 | `07-ordenar.php` | `usort` |
| 8 | `08-carrinho.php` | Nested structure: subtotal, total, most expensive item |

### What I learned building this project

- Associative, numeric, and nested arrays in PHP
- Array helpers: `min`, `max`, `array_sum`, `count`, `array_column`
- `array_filter`, `array_map`, and `array_reduce`
- Sorting with `sort` and `usort`
- Walking nested structures (product → prices, cart → items)

### Tech stack

- PHP
- Git
